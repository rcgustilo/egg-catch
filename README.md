# Egg Catch

A retro LCD handheld-style arcade game for Android. Four hens lay eggs that roll down four ramps, one step at a time. Move the farmer's basket to the right ramp before each egg drops.

- **Controls:** the four yellow buttons (upper-left, lower-left, upper-right, lower-right), or tap the matching quarter of the screen.
- **Game A** is normal speed; **Game B** is faster with more eggs at once.
- The game speeds up as your score rises. Three broken eggs end the game. Reaching 200 and 500 points clears your misses.
- High scores for A and B are saved. Sound can be switched off from the menu. Back pauses the game.

The APK is built by GitHub Actions on every push and published under Releases.
